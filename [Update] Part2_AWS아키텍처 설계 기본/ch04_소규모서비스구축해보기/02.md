# 이벤트/함수 오류 탐지 설계 문서

> 목적: dewsGrid2로 변환된 메뉴에서 그리드 이벤트/함수에 오류가 있는지 자동 탐지
> 상태: 설계 단계 (구현 전)
> 참조: grid접근규칙/ColumnRule.md, grid접근규칙/grid.md, grid접근규칙/dews.d.ts

---

## 핵심 목표

```
메뉴 HTML에서 이벤트 핸들러 본문 내 그리드 함수 호출 정적 추출
  ↓
추출된 함수들을 대상 그리드에 직접 실행
  dews.ui.page["targetGridId"].funcName(기본값 파라미터)
  ↓
오류(예외) 유무 판단 → 리포팅
```

---

## 기존 방식 vs 새 방식

| 항목 | 기존 (이벤트 전체 실행) | 새 방식 (함수만 추출 실행) |
|------|----------------------|------------------------|
| 실행 단위 | 이벤트 핸들러 전체 | 핸들러 내부 그리드 함수 호출 |
| mock e 필요 | ✅ 필요 | ❌ 불필요 |
| side effect | ✅ 핸들러 로직 전체 실행 | ❌ 함수 호출만 실행 |
| 에러 원인 명확성 | ⚠️ 핸들러 로직 문제인지 불명확 | ✅ 해당 함수 문제임이 명확 |
| 탐지 목적 | 이벤트 동작 전체 검증 | dewsGrid2 API 존재/동작 검증 |

### 추출 예시

```javascript
// 원본 메뉴 이벤트 핸들러
change: function(e) {
  if (e.row.data) {
    verifyMap[e.row.data.HWND_ID_CD] = self.grid.dataItems();
    //                                             ↑ 추출
  }
},
save: function(e) {
  self.gridParam.setCheckedAll(false);  // ← 추출
  self.gridParam.cancelAll();           // ← 추출
},
rowAdd: function(e) {
  self.gridParam.getCellValue(e.row.index, 'COL1');  // ← 추출
},
pasted: function(e) {
  self.gridParam.dataItems();  // ← 추출
}
```

```javascript
// 이벤트 핸들러 전체를 실행하는 게 아니라
```

### STEP 1 — 정적 추출 (HTML 파싱)

#### 목표
```
메뉴 HTML 파일에서
  1. 그리드 ID 목록 추출
  2. 컬럼 스키마 추출 (field, editor.type) → mock 데이터 생성용
  3. 각 이벤트 핸들러 본문에서 그리드 함수 호출 목록 추출
```

#### 선행조건
```
✅ poc/samples/new/ 하위 HTML 파일 접근 가능 (변환된 dewsGrid2 파일)
✅ C# HtmlGridIdExtractor 패턴 참조 (그리드 ID 추출)
✅ C# HtmlFunctionDetector 패턴 참조 (함수 호출 추출)
✅ C# HtmlEventDetector 패턴 참조 (이벤트 블록 범위 추출)
```

#### 추출 흐름

```
HTML 파싱
  ↓
dews.ui.grid(anyPrefix.$gridId, { ... }) 패턴으로 그리드 블록 찾기
  ↓
각 이벤트 핸들러 본문 추출 (depth-1 이벤트명 → 본문 { ... })
  ↓
핸들러 본문에서 그리드 함수 호출 추출:
  패턴 1: gridId.funcName(         → gridId = 추출된 그리드ID
  패턴 2: self.gridId.funcName(    → gridId = 추출된 그리드ID
  패턴 3: dewself.gridId.funcName( → gridId = 추출된 그리드ID
  패턴 4: e.grid.funcName(         → gridId = 해당 이벤트의 그리드ID
  ↓
함수명 중복 제거 + 위험도 태깅
  ↓
event-list.json 생성
```

```javascript
  'numeric' : 0,
  'integer' : 0,

// 3. mock 데이터 주입
```

```javascript
// 파라미터가 필요한 함수에 대한 기본값 매핑
const FUNC_DEFAULT_ARGS = {
  getCellValue    : (grid) => [0, grid.getColumns()?.[0]?.field || ''],
  getCellData     : (grid) => [0, grid.getColumns()?.[0]?.field || ''],
  setCellValue    : (grid) => [0, grid.getColumns()?.[0]?.field || '', ''],
  dataItem        : ()     => [0],
  select          : ()     => [0],
  deselect        : ()     => [0],
  getColumnIndex  : (grid) => [grid.getColumns()?.[0]?.field || ''],
  getColumn       : (grid) => [grid.getColumns()?.[0]?.field || ''],
  setColumnVisible: (grid) => [grid.getColumns()?.[0]?.field || '', true],
  setColumnTitle  : (grid) => [grid.getColumns()?.[0]?.field || '', ''],
  focus           : ()     => [0],
  // 파라미터 없는 함수 (기본값 불필요)
  // dataItems, getColumns, cancelAll, setCheckedAll, getCheckedItems 등

```

#### 실행기 구조 (safeExecuteFunction)

```javascript
// page.evaluate() 내부에서 실행
async function safeExecuteFunction(gridId, funcName) {
  const result = {
    gridId,
    funcName,
    status : 'OK',       // OK | ERROR | NOT_FOUND | SKIPPED
    message: null,
    stack  : null
  };

  try {
    const grid = dews.ui.page[gridId];
    if (!grid) {
      result.status = 'NOT_FOUND';
      return result;
    }

    // 함수 존재 여부 확인
    if (typeof grid[funcName] !== 'function') {
      result.status  = 'NOT_FOUND';
      result.message = `${funcName}() 함수가 dewsGrid2에 존재하지 않음`;
      return result;
    }

    // 기본 파라미터 결정
    const argsBuilder = FUNC_DEFAULT_ARGS[funcName];
    const args = argsBuilder ? argsBuilder(grid) : [];

    // 함수 직접 실행
    const ret = grid[funcName](...args);

    // Promise 반환 시 (async 함수)
    if (ret && typeof ret.then === 'function') await ret;

  } catch(err) {
    result.status  = 'ERROR';
    result.message = err.message;
    result.stack   = err.stack?.split('\n').slice(0, 5).join('\n');
  }

  return result;
}
```

```javascript
  focus           : ()     => [0],
};
```
